Minion 0.4.2 — for High Sierra, Intel (x64)
====================================================

What this is
------------
Minion is the Detroit Automation Academy's desktop client, assembled
on Electron 22.3.27 — the last Electron line that runs on
macOS 10.13 — so it can launch on Intel Macs running High Sierra.
It is a focused window onto its hosted service, reached over HTTPS
through the app's API endpoint, with its own browser profile, native
notifications, and the system file picker for uploads. The
application layer is open source (MIT). It is an unofficial build:
not a Meta product and not endorsed by Meta.

Minion is the app's name on every surface — bundle Minion.app under
the Academy bundle identity com.detroitautomationacademy.minion,
with the Minion mark: the scheming side-eye dog, rendered to the
Academy monochrome standard (white tile, ink artwork, no black
field). Version 0.4.2 is identified by version alone.

New in 0.4.2: sign-in is repaired. The 0.4.1 build renamed two
plumbing identities along with the app's display name — the
session partition (the session store's identity) and the package
identity the session machinery derives from — and sign-in broke:
an existing sign-in was left behind, and a fresh sign-in spun
forever after the two-factor step. This build restores both
plumbing identities to the values the working builds used, so a
sign-in made in an earlier build carries into this one and a
fresh sign-in completes. (A sign-in made inside 0.4.1's own
separate session store is not read here; if 0.4.1 was the only
build you ran, sign in once more.) Nothing about the app's name
or surfaces changes. The window title bar reads Minion (the
hosted page's own
title never replaces the app's name in the title bar), and the app
presents DARK by default: a fresh profile opens dark. Dark is the
default, not a lock — View menu → Appearance (Dark / Light /
System) records your explicit choice, and that choice is what
later launches apply. Everything standing from the earlier 0.4.0
builds stands:

- Terminal (View menu, or Command-T). A real terminal window of the
  app's own: monochrome, monospace, a scrollback, and a prompt line
  (minion ❯) with a proper bordered text field. Type a message and
  press Enter and it is sent to Minion through this app's live
  hosted session — the terminal drives the main window's message
  box and reads the reply from the conversation as it renders.
  Up/down arrows recall what you have sent; /help lists the local
  commands (/clear, /view).
- Up-arrow message history. In the message box, press the up arrow
  to recall messages you have sent in this conversation, shell-style:
  up steps older, down steps newer, your half-typed draft is kept
  and restored when you step back down, and editing a recalled
  message changes nothing until you send it. History is per
  conversation and is stored only on this Mac, in the app's own data
  folder. Clear it any time from the View menu.
- Markdown files open in MacDown. A .md / .markdown file you
  download here opens in MacDown (the Academy's markdown editor)
  instead of piling up in Downloads; the View menu can switch that
  to Ask Each Time or the system default. After the first routed
  file, the app offers — once, and only with your explicit yes — to
  make MacDown the default for markdown files everywhere on the
  Mac; the previous default is recorded first and restored if you
  later uncheck the View-menu item. Plain text files are never
  touched.
- An SDS-8 welcome screen on first launch, and a window law: no
  window of this app opens partially off-screen, and the main
  window reopens where you left it.

Minion keeps no user data inside the app bundle. Its data lives at
~/Library/Application Support/com.detroitautomationacademy.minion
— a location keyed to the bundle identity, created on first
launch.

It is NOT signed or notarized (no Apple Developer identity), so macOS
will warn on first launch. That is expected.

Install (on the MacBook Air running 10.13)
------------------------------------------
1. Copy Minion-1013-x64.zip to the Mac and double-click it to
   unzip. You get Minion.app.
2. Drag Minion.app into your Applications folder.
3. First launch: right-click (or Control-click) Minion.app and
   choose Open, then click Open in the dialog. (A plain double-click
   will be blocked by Gatekeeper because the app is unsigned; the
   right-click route is the one-time bypass.)
4. Sign in with your Meta account in the window that opens. Minion
   has its own fresh data store (below): expect to sign in again,
   and expect a fresh start.

Notes
-----
- Minion's data lives outside the bundle, in its own Application
  Support location: ~/Library/Application Support/
  com.detroitautomationacademy.minion — delete that folder to sign
  out and reset Minion completely. The Academy state (message
  history, preferences) lives in the same folder, in
  academy-state.json. Removing the Minion.app bundle never touches
  the data store.
- Downloads from Minion are saved to your Downloads folder, never
  overwriting an existing file of the same name.
- Links that leave Minion open in your default browser; sign-in
  popups (Meta/Facebook/Instagram) open inside managed child
  windows.
- This app cannot update itself. New builds arrive through Distro,
  the Academy's High Sierra app store, and nowhere else.
